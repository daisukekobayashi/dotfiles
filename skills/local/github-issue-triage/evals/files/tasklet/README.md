# tasklet

tasklet is a small command-line task tracker that stores tasks in a local file.

## Core features

- `tasklet add` and `tasklet list` record and show tasks. Delivered.
- `tasklet export` writes tasks to CSV for spreadsheets and CI reports. This is
  the core feature in progress, tracked by the `export-v1` milestone.

## Next

- `tasklet sync` exchanges tasks with a remote server. Upcoming core feature,
  not started.

## Out of scope

- A graphical interface and third-party plugins.
